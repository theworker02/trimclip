# trimclip

Trim encode/decode helpers for clip payloads in pipelines.

**Site:** https://theworker02.github.io/trimclip/

## Install / run

```bash
git clone https://github.com/theworker02/trimclip.git
cd trimclip
node src/cli.js
node --test
```
